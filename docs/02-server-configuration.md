# Module 2: Express Server Configuration

To host a React app on Node.js, Express must serve the static files generated by the React build process.

---

## 🚀 1. The Server Code (`index.js`)
Create an `index.js` in the root folder with the following logic:

```javascript
const express = require('express');
const path = require('path');
const app = express();

// Use the port provided by Hostinger or 3000 for local testing
const PORT = process.env.PORT || 3000;

// Serve static files from the React 'dist' folder
app.use(express.static(path.join(__dirname, 'frontend', 'dist')));

/**
 * Essential for Single Page Applications (SPA): 
 * Redirect all requests to index.html so React Router works.
 */
app.get('*', (req, res) => {
    res.sendFile(path.join(__dirname, 'frontend', 'dist', 'index.html'));
});

app.listen(PORT, '0.0.0.0', () => {
    console.log(`Server running on port ${PORT}`);
});
```

## 📦 2. Dependencies & Best Practices
*   **Express**: Ensure `package.json` includes `express` in `dependencies`.
*   **Cleanup**: Avoid including `package-lock.json` in manual ZIP uploads to prevent dependency path errors on Hostinger.
*   **Port Handling**: Always use `process.env.PORT` to allow the hosting environment to assign the port.
